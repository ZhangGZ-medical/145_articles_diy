# 145_articles_diy

文献元数据批量采集与结构化填表技能。

## 功能

输入论文名称列表 → 自动从 Crossref API、PubMed、期刊分区平台等多源采集完整书目信息 → 按标准化11列表格输出。

## 输出表格

| 序号 | 论文名称 | 作者姓名 | 单位 | 所属会议/期刊（期刊号） | 刊物级别 | 投稿日期 | 收录或发表日期 | 论文内容与项目关系 | 页码 |

## 数据源

- **Crossref API**：作者、单位、期刊、ISSN、日期、页码、DOI
- **iikx.com / Bioxbio**：中科院分区、JCR分区、影响因子、SCIE收录状态
- **PubMed / Europe PMC**：PMID、Accepted日期、摘要
- **Semantic Scholar**：备用查询（有rate limit）

## 论文内容与项目关系

固定三段式模板（中文撰写）：

```
论文提出了......，研究了......，有助于......。
```

## 使用方式

1. 提供论文名称列表
2. 明确项目全称（用于"论文内容与项目关系"字段）
3. 等待逐篇调研结果确认
4. 全部完成后输出 xlsx 文件

## 触发词

文献调研、论文信息采集、文献元数据、填文献表、sci论文信息汇总
